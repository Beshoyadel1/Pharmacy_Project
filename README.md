# Pharmacy Management System

A desktop pharmacy management system built with Java and JavaFX, backed by a SQL database. Manages inventory, employees and branches.

## Features

- Medicine inventory: stock, expiry and quantities
- Employee management with roles
- Multi-branch support
- Sales and reporting
- JavaFX desktop UI

## Tech Stack

- Java
- JavaFX (FXML views)
- SQL database

## Project Structure

- `src/pharmacy_project/` - Java sources and FXML views
